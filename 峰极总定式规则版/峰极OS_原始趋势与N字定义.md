## 0. 一句话

> **峰极 OS 判的是「原始趋势（N 字）+ 阵营身份」，不是 K 线高低点的几何标签。**

红蓝阵营是市场**政权**（向上政权 / 向下政权），不是涂色。  
**峰 = 进攻**（攻击方向上的节点）；**极 = 防守**（相反方向上的防守线）。  
**假红峰 / 假蓝峰仍是峰**，不是极，更不是杂点。

## 1. 废止的旧口径（禁止再犯）

| 旧误区 | 正确口径 |
|--------|----------|
| HIGH 叫峰、LOW 叫极 | 身份由**当前政权 + N 字角色**决定 |
| 机械「峰-极-峰-极」交替标注 | 允许 **红峰→蓝极**、**蓝峰→红峰** 等身份跃迁 |
| 破一下防守线就算转势 | 须**破坏原政权正向 N**，走出**反向 N 骨架**后才算转势 |
| 假峰是失败杂点 | 假峰是**未完成的进攻峰**，破假峰 + 同向 N 延续可升格为真峰 |
| 等下一根 3-3 点才转势 | 转势触发在**刺破当前政权防守极**的瞬间（但须满足 N 字前提） |

## 2. 政权与进攻/防守（不变内核）

### 红阵营（向上政权）

```text
红峰 = 向上进攻点（真峰 / 假红峰 均属「峰」）
红极 = 向下防守点
原始趋势 = 正向 N 字（一浪高过一浪）
```

### 蓝阵营（向下政权）

```text
蓝峰 = 向下进攻点（真峰 / 假蓝峰 均属「峰」）
蓝极 = 向上防守点
原始趋势 = 反向 N 字（一浪低过一浪）
```

**记忆法（对照 `红蓝阵营转势与af中间失败点身份转化.png`）：**

- 红政权：峰在上、极在下 → 正向 N 向上开口  
- 蓝政权：峰在下、极在上 → 反向 N 向下开口

## 3. 原始趋势 = N 字（核心新增）

### 3.1 正向 N（红政权原始趋势）

结构示意（`峰极图01.png` 左段）：

```text
红极1 → 红峰2 → 红极3 → 红峰4 → … → 红极9 → 红峰8
         ↑正向N↑              ↑正向N↑
```

**正向 N 成立条件（红政权内）：**

1. 每一个**红峰**高于前一个红峰（进攻抬升）；  
2. 每一个**红极**高于前一个红极（防守抬升）；  
3. 峰、极在硬化物理线上按 3-3/T+3 释放，但**身份**由 N 字逻辑审计，不由几何交替代替。

**假红峰 a（`真峰假峰.png`）：**

- 位置：低于真红峰 8，高于红极 9；  
- 性质：**仍是峰**（一次失败的向上进攻），暂不入正式红峰/红极表；  
- 若后续**同向正向 N 再成立**（例如启动棍突破 a），a 可升格为真红峰；  
- 若**正向 N 被破坏**且走出反向 N，a 参与**转势身份重定义**（见 §4）。

### 3.2 反向 N（蓝政权原始趋势）

结构示意（`红蓝阵营转势与af中间失败点身份转化.png` 右段）：

```text
蓝极a → 蓝峰b → 蓝极c → 蓝峰d → 蓝极e → 假蓝峰f → …
         ↑反向N↑              ↑反向N↑
```

**反向 N 成立条件（蓝政权内）：**

1. 每一个**蓝峰**低于前一个蓝峰（向下进攻加深）；  
2. 每一个**蓝极**低于前一个蓝极（向上防守下压）；  
3. **假蓝峰 f**：高于蓝峰 d、低于蓝极 e，是**失败的向下进攻峰**，不是极。

### 3.3 同向 N 与反向 N 的关系

| 概念 | 含义 |
|------|------|
| **同向 N** | 与当前政权一致：红政权内连续正向 N；蓝政权内连续反向 N |
| **反向 N** | 与原政权相反：红政权内出现「高点不再抬高 + 低点跌破前红极」的镜像结构 |
| **转势（camp）** | 以图片逻辑为准：B类假峰链转势、C类急转势、整根脱离转势均允许在破极瞬间切换当前阵营 |
| **政权确认（camp_confirmed）** | 当前合法阵营授权字段，可给 DS07/DS09 等跨周期授权；不是新理论 |
| **普通破极** | 没有假峰链、也不满足C类急转势或整根脱离条件时，不得强行转势 |

**关键（图片逻辑为最高准绳）：**

- **B类**：有假峰 + 破极 + 重定义 → `camp` 切换，`camp_confirmed` 同步为新阵营。
- **C类**：攻峰已确立后直接破前极 → `camp` 切换，可无标准假峰链。**（2026-06-10 N04 修订）无 a/f 假峰可重定义时，破极瞬间把启动前旧蓝峰重定义为新红极、旧红峰重定义为新蓝极，防守极不得为空。**
- **脱离类**：整根 K 完全低于红极 / 高于蓝极 → `camp` 切换，避免陈旧锚点卡死。同 C 类适用 N04 防守极重定义。
- 合法破极转势一旦切 `camp`，`camp_confirmed` 必须同步；禁止旧阵营授权残留。
- **DS07** 只读 `camp_confirmed` 作 D1 授权；H1 须 DS03 二四棒且与 D1 同向；**与 DS01/DS02 无关**。

## 4. 转势与身份重定义（对照三图）

### 4.1 红转蓝（正向 N 被破坏 → 进入反向 N）

触发链（`红蓝阵营转势与af中间失败点身份转化.png`）：

```text
红政权运行中 → 出现假红峰 a（攻 8 失败）
→ 价格刺破红极 9
→ 红转蓝（政权切换）
→ a 重定义为 蓝极（假红峰 → 蓝极）
→ 随后 b、d 为 蓝峰，c、e 为 蓝极（反向 N 展开）
```

**身份跃迁示例：** `红峰 8` 保留为历史真峰；`假红峰 a` **不是**「变成蓝峰」，而是**失败进攻峰在破极后升格为新政权防守极 → 蓝极**。

### 4.2 蓝转红（反向 N 被破坏 → 回到正向 N）

触发链（标准图 + `阵营转换通用版.docx`）：

```text
蓝政权内：… 蓝峰 d — 蓝极 e — 假蓝峰 f（向下攻失败）
→ g 刺破蓝极 e
→ 蓝转红
→ f 重定义为 红极
→ g 成为红峰（新政权进攻起点）
```

**`真峰假峰.png` 变体（复杂转折）：**

```text
正向 N 末段出现 a(假峰)–b(极)–c(峰，可带启动棍)–d(极)
→ e 为假峰
→ f 刺破 d 的极点
→ e 重定义为 蓝极
```

说明：同一段行情可用「破 e」或「f 破 d 后 e 变蓝极」两种图示表达**同一原则**——  
**先破坏原趋势 N 字，再对假峰/失败结构做身份重定义，最后才切换政权。**

### 4.3 峰与峰之间的直接跃迁（`峰极图01.png`）

废止「只能峰→极→峰→极」后，允许：

```text
假红峰 ──破极转势──→ 蓝极
蓝峰 ──破蓝极+N完成──→ 红峰
红峰 ──破红极+N完成──→ 蓝峰（镜像）
```

标注时必须写清**身份名**（红峰/红极/蓝峰/蓝极/假红峰/假蓝峰），禁止只写「峰」「极」两字。

## 5. 真峰、假峰与 3-3 释放（`真峰假峰.png`）

| 类型 | 定义 | 能否当极 |
|------|------|----------|
| 真红峰 | 红政权内突破前高的进攻高点 | 否 |
| 假红峰 a | 未破前真峰、高于红极的失败进攻高点 | 否（转势前）；破红极后 → **蓝极** |
| 真蓝峰 | 蓝政权内跌破前低的进攻低点 | 否 |
| 假蓝峰 f | 未破前真低、低于蓝极的失败进攻低点 | 否（转势前）；破蓝极后 → **红极** |
| 红极 / 蓝极 | 当前政权防守线 | 是 |

**3-3 / T+3：** 只解决「物理点何时释放可见」，**不替代** N 字与转势审计。  
释放后的点，仍须过 §3–§4 身份判定，才能称为峰或极。

## 10. 工程实现（2026-05-29 已对齐）

`packages/fengji_core/fengji_core/os_engine.py`：

```text
B类：假峰/假极探针 + 破防守极 → camp 转势（可重定义）
C类：攻峰已确立后直接破前极 → camp 转势（可无假峰链，§4.7）
脱离：整根 K 完全低于红极 / 高于蓝极 → camp 转势
假峰重定义 + 新N首腿(gap≥3) → camp_confirmed 稳定
camp_confirmed 才用于 DS07 / DS09 战略授权
A类破峰 → DS03；B/C类破极 → DS01 / DS02
废除 fallback 身份跃迁
```

> **2026-06-10 N04 修订注解：** 上方「废除 fallback 身份跃迁」指的是**无破极**的 fallback（未破防守极不得擅自跃迁身份）。依本文件夹 `N字突破04.png`：C 类急转势/整根脱离且**无 a/f 假峰可重定义**时，**破极/转势瞬间**允许把启动前的旧蓝峰直接重定义为新红极、旧红峰直接重定义为新蓝极（防守极不得为空）。该重定义只发生在破极瞬间，仍禁止「无破极」的 fallback。破极口径：影线刺破、收盘跌破、与极点平级都算破极。

| 定稿要求 | 工程字段 |
|----------|----------|
| 破极=转势（图03底色） | `camp` + `turns` |
| 合法转势后同步战略授权 | `camp_confirmed = camp` |
| 旧延迟确认字段 | `pending_turn` 仅保留兼容/审计，不再阻止合法转势授权 |
| 结构沙盒底色 | `plot_fengji_structure.py` 读 `camp` |
| DS03 只破峰 | `resolve_ds03_attack` 不变 |
| DS07 D1 授权 | `map_d1_to_h1_*` 用 `camp_confirmed` |
