# DS01 Calibration

DS01 挫棍已按当前项目最高 OS 完成校准。

## 继承关系

DS01 必须继承当前项目最高 OS：

- `hardened_fengji_line`
- 当前红蓝阵营转换规则
- 当前峰极确认与硬化规则

旧文档只参考 DS01 自身买卖逻辑，不参考旧OS。

## 当前草案买卖逻辑

首仓：

- 必须处于红/蓝阵营。
- 昨日同方向K线成立：
  - 红阵营：昨日阳线。
  - 蓝阵营：昨日阴线。
- 次日盘中刺破昨日高/低时，在触发价位置同步检查左30无线。
  - 红阵营：昨日阳线，次日突破昨日最高点，且突破价位置左30无线，立即做多。
  - 蓝阵营：昨日阴线，次日跌破昨日最低点，且跌破价位置左30无线，立即做空。
- 左30无线不是昨日收盘价过滤；它必须在次日突破/跌破触发价位置判断。

续棍：

- 已有持仓时允许续棍。
- 最多 3 根。
- 续棍暂不看左线。

止损：

- 多头开仓后先守前一天信号K线低点；当日收盘后，把次日止损移动到当日低点。
- 空头开仓后先守前一天信号K线高点；当日收盘后，把次日止损移动到当日高点。

校准备注：

- 已新增 `stop_mode=trigger` 对固定守触发K口径做全品种对照。
- 该口径在国内期货 30 品种上出现极端长持仓和接近归零回撤，暂不作为当前校准基线。
- 当前工程 `stop_mode=one_bar` 已确认符合 DS01 一棍止损定义。
- 详见 `docs/DS01_CALIBRATION.md`。
