## 当前最高 OS 迁移

- DS07 继承当前峰极 OS 最高宪法。
- D1 与 H1 必须分别独立运行完整峰极 OS。
- 旧文档只读取 DS07 自身买卖逻辑，不读取旧 OS。
- 当前峰极间隔统一使用 `gap=3`，不是旧文档里的 `gap=4`。
- H1 当前 K 只能读取上一根已收盘 D1 的阵营状态，禁止读取当天未收盘日线。

## 多头逻辑

1. D1 安全桥接阵营为红：`d1_camp == 1`。
2. H1 当前阵营也为红：`h1_camp == 1`。
3. H1 存在当前红峰与红极。
4. H1 当前 K 线向上攻击红峰：`high > red_peak`。
5. 同一个 `red_peak_idx + red_peak_price` 只能消费一次。
6. 入场价为 `max(open, red_peak)`。
7. 初始止损守 H1 红极：`stop = red_ext`。
8. 后续只接受更高的 H1 红极上移止损。

## 空头逻辑

1. D1 安全桥接阵营为蓝：`d1_camp == -1`。
2. H1 当前阵营也为蓝：`h1_camp == -1`。
3. H1 存在当前蓝峰与蓝极。
4. H1 当前 K 线向下攻击蓝峰：`low < blue_peak`。
5. 同一个 `blue_peak_idx + blue_peak_price` 只能消费一次。
6. 入场价为 `min(open, blue_peak)`。
7. 初始止损守 H1 蓝极：`stop = blue_ext`。
8. 后续只接受更低的 H1 蓝极下移止损。

## 审计硬条件

- D1 与 H1 必须分别是完整峰极 OS 结果，不能用裸 K 线替代。
- `d1_camp` 必须来自上一根已收盘 D1 的安全状态。
- 多头必须 `d1_camp=1` 且 `h1_camp=1`。
- 空头必须 `d1_camp=-1` 且 `h1_camp=-1`。
- 攻击点必须是 H1 当前阵营的进攻峰：多头红峰，空头蓝峰。
- 防守点必须是 H1 当前阵营的防守极：多头红极，空头蓝极。
- 同一攻击峰只允许触发一次，止损后不得重复消费同一结构。
- 止损只守 H1 防守极，并且只向有利方向移动。
